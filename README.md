✨ About the Project

Mahal is a visually rich website celebrating the grandeur, elegance, and architectural beauty of India's royal palaces.

The project combines traditional Indian heritage with contemporary web design to create an engaging, luxurious, and immersive browsing experience.

From striking imagery to smooth transitions, every design element aims to capture the atmosphere of royalty and timeless elegance.

🎨 Key Features

🏛️ Royal Visual Identity — A luxurious aesthetic inspired by Indian palace architecture.

🎬 Cinematic Experience — Visually engaging layouts and immersive imagery.

✨ Smooth Animations — Elegant transitions and interactive elements.

📱 Responsive Design — Adaptable layouts for desktop, tablet, and mobile.

🖋️ Elegant Typography — Carefully balanced typography and visual hierarchy.

🧭 Intuitive Navigation — A user-friendly browsing experience.

⚡ Modern Development — Built with contemporary frontend technologies.
